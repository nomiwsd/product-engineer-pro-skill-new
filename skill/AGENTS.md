# Product Engineer Pro portable fallback

Load `SKILL.md` from this directory when file access is available. Select two
independent values for every task: lifecycle (`plan`, `build`, or `review`) and one
specialty (`audit`, `backend`, `database`, `debug`, `design-system`, `frontend`,
`implement`, `performance`, `refactor`, `review`, `security`, `seo`, or `test`).

Host state controls mutation. In Plan, Ask, or read-only mode, inspect and return a
decision-complete plan without editing. In an editing mode, "find and fix" authorizes
scoped diagnosis and repair; audit/report/review requests remain read-only.

Read before writing, match repository conventions, detect installed versions, avoid
unrelated changes, validate trust boundaries, and run proportionate checks. Never
weaken host permissions or safeguards, fabricate APIs/configuration, hardcode secrets,
or execute destructive changes without explicit confirmation.

This is a portable fallback. It does not claim native commands, agents, progressive
loading, or enforceable modes in a host that does not provide them.
